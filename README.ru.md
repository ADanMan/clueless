Вы это тоже замечали. Стоит написать «я в этом не разбираюсь, просто сделай нормально за меня», и ответ становится *лучше*. Модель перестаёт рассчитывать, что вы поймаете её ошибки. Начинает называть то, о чём вы не догадались спросить. Помечает шаг, который стоил бы вам данных.

Это не случайность. Это переворот ответственности: как только модель верит, что её работу никто не проверит, она сама становится проверяющим.

**clueless делает этот переворот намеренным и постоянным.**

## До / после

Вы просите форму регистрации и говорите, что не программист.

Без clueless вы получаете рабочий код, а в самом низу, под заголовком *«несколько вещей, которые стоит знать (ничего делать не нужно)»*, заметку, что секрет сессии всё ещё `change-this-to-a-random-long-string`. Вы копируете. Оно уезжает в прод.

С clueless:

```
Сделайте
  1. Создайте .env с SESSION_SECRET=<сгенерирован ниже>. Без него сервер не запустится.
  ...
Осторожно
  - users.db хранит email живых людей. Бэкапьте, не коммитьте, не пересылайте почтой.
  - Нет сброса пароля. Для сайта курса это тикет номер один в поддержку. Скажите, и добавлю до запуска.
Проверьте, что работает
  Зарегистрируйтесь дважды с одним email. Второй раз должно сказать «уже существует».
Решил за вас
  - SQLite вместо Postgres: один файл, ноль настройки, хватит на несколько сотен студентов.
  - bcrypt cost 12 вместо 10: медленнее на 300 мс, безопаснее, если файл когда-нибудь утечёт.
Решить можете только вы
  - Где это будет хоститься (предположил Render; для VPS шаги другие).
```

Та же модель. Тот же промпт. Ещё примеры в [examples/](examples/).

## Что он делает на самом деле

Перед каждым ответом агент задаёт себе четыре вопроса, которые обычно пропускает, когда думает, что вы проверите результат:

1. **Что спросил бы эксперт, о чём этот пользователь не спросил?** И отвечает на это сам, безопасными дефолтами, прямо внутри результата.
2. **Что здесь необратимо или дорого?** Потеря данных, деньги, безопасность, юридика, запертые снаружи клиенты, дедлайны. Это идёт наверх, простыми словами, а не в заметку в конце.
3. **Что я только что решил за пользователя?** Каждый инструмент, провайдер, ставка или дефолт называется вместе с альтернативой и одной строкой «почему».
4. **Как он узнает, что сработало?** Проверяет сам, если может. Если может только пользователь, даёт одну проверку, которая заметно ломается.

Дальше отдаёт результат в фиксированной форме: **Сделайте → Осторожно → Проверьте → Решил за вас → Решить можете только вы.** Последний блок ограничен тремя пунктами, в каждом уже вписано предположение, так что молчание тоже ответ.

Это не «объясни попроще». Это *будь единственным взрослым в комнате*.

## Цифры

Три промпта в духе «я ничего не знаю, сделай за меня» (домашние бэкапы, налоги фрилансера в первый год, форма регистрации для непрограммиста), по три прогона, та же модель, со скиллом и без. Каждый ответ оценён по фиксированному списку того, на чём настоял бы эксперт. Пункт засчитывается, только если сказано ясно и с действием, а не спрятано под «просто контекст».

| | без скилла | clueless |
|---|:-:|:-:|
| Экспертных пунктов сказано ясно | 12 / 63 | **47 / 63** |
| Есть, но спрятано | 13 / 63 | 4 / 63 |
| Нет вообще | 38 / 63 | 12 / 63 |

| Промпт | без скилла, по прогонам | clueless, по прогонам |
|---|:-:|:-:|
| домашние бэкапы | 3, 3, 2 из 7 | 7, 6, 6 из 7 |
| налоги фрилансера, первый год | 2, 1, 1 из 7 | 4, 4, 4 из 7 |
| форма регистрации, непрограммист | 0, 0, 0 из 7 | 5, 5, 6 из 7 |

n=3 на промпт на сторону, одна модель, оценка отдельной моделью по фиксированному чек-листу. Мало, но прогоны между собой сходятся. Что скилл пропускает каждый раз: сброс пароля для сайта курса, бумаги W-9/1099, правило safe harbor по налогам за первый год. Метод, чек-листы, все 18 ответов и оценки: [benchmarks/](benchmarks/).

Базовые ответы были грамотными. Не хватало формы: оговорки внизу, решения не названы, проверить нечем.

## Установка

### Claude Code

```
/plugin marketplace add ADanMan/clueless
```
```
/plugin install clueless@clueless
```

Два отдельных сообщения. В десктопном приложении Claude Code то же самое во вкладке Code.

### Codex

```bash
codex plugin marketplace add ADanMan/clueless
codex plugin add clueless@clueless
```

### Cursor

Скопируйте [`.cursor/rules/clueless.mdc`](.cursor/rules/clueless.mdc) в `.cursor/rules/` своего проекта. Правило помечено `alwaysApply`.

### Всё, что читает `AGENTS.md`

OpenCode, Jules, Amp, CodeWhale, Qoder, Swival и остальные подхватывают [`AGENTS.md`](AGENTS.md) из корня репо. Скопируйте в свой проект или работайте из чекаута.

### Удаление

`/plugin remove clueless` (Claude Code), `codex plugin remove clueless` (Codex) или удалите скопированный файл правила. За пределы папки плагина ничего не пишется.

## Команды

| Команда | Что делает |
|---------|------------|
| `/clueless [lite \| full \| ultra \| off]` | Сколько ответственности берёт агент. Без аргумента сообщает текущий уровень. |
| `/clueless-blindspots` | Разово: что вы не видите в плане, коде или документе перед вами. Список с тегами, самое рискованное первым. |
| `/clueless-help` | Краткая справка. |

| Уровень | Что меняется |
|---------|--------------|
| **lite** | Обычный ответ плюс только блоки *Решил за вас* и *Решить можете только вы*. |
| **full** | Весь контракт. По умолчанию. |
| **ultra** | Ещё и оспаривает саму задачу первой строкой, как сделал бы профессионал: «Вы просили X; людям в вашей ситуации обычно нужен Y». |

## FAQ

**Это не то же самое, что «объясни как пятилетнему»?**
Нет. ELI5 меняет словарь. clueless меняет, кто отвечает. Ответ может быть коротким; он не может быть непроверенным.

**Совместим с [ponytail](https://github.com/DietrichGebert/ponytail)?**
Да. ponytail управляет тем, сколько агент строит; clueless тем, за сколько он отвечает. Ленивый код, аккуратно сданный.

**Агент станет задавать больше вопросов?**
Наоборот. Вопрос, на который вы не можете ответить, это решение, от которого агент увильнул. Он решает, называет дефолт и оставляет максимум три пункта, которые можете закрыть только вы, с уже вписанным предположением.

**А если я на самом деле эксперт?**
Тогда не говорите, что clueless. Скилл и сам отступает, как только вы начинаете построчно проверять его вывод.

**Почему «clueless»?**
Потому что вы именно это и написали, и это сработало.

## Хук калибровки

Claude Code автоматически загружает `UserPromptSubmit`: хук просит модель оценить,
какую часть текущей задачи пользователь сможет проверить, по каталогу паттернов.
Он не выбирает режим программно, не хранит запросы, не вызывает отдельную модель
и не расширяет разрешения. Для хука нужен Node.js; остальные адаптеры используют
правила скилла без хука.

Отключение: `CLUELESS_CALIBRATION=off` перед запуском Claude Code. Явные команды
уровня и выключения имеют приоритет. Напоминание добавляет контекст на каждом ходе.

Опубликованные цифры относятся к предыдущим версиям скилла. Тесты проверяют
работу хука, но точность калибровки и пользу в длинных сессиях пока не измеряли.
